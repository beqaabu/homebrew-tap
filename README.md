# beqaabu/tap

Homebrew tap for my macOS apps.

```sh
brew install --cask beqaabu/tap/missionclose
brew install --cask beqaabu/tap/snappy-app
```

## Casks

- [**missionclose**](https://github.com/beqaabu/MissionClose) — close, minimize and full-screen buttons for windows in Mission Control.
- [**snappy-app**](https://github.com/beqaabu/Snappy): Ubuntu-style screenshots: drag a selection, pick a window or grab the whole screen.
